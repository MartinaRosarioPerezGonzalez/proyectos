# Repositorio Personal

Colección de proyectos personales y académicos en áreas de IA, análisis de datos y desarrollo de software.

---

## Proyectos

### [Aprobación de Créditos — OCR con IA](Aprobacion-creditos-OCR/)
Sistema que extrae datos estructurados de documentos PDF (DNI y recibos de sueldo) para asistir al analista bancario en la evaluación de solicitudes de crédito hipotecario. Usa IBM Watsonx.ai con visión multimodal y un modelo de lenguaje para estructurar la información en JSON con alertas automáticas.

**Stack:** Python, FastAPI, IBM Watsonx.ai (Mistral Vision + GPT-OSS-120B)

---

### [Evolución del Ecosistema Python (2016–2025)](Evolucion-ecosistema-python/)
Análisis topológico comparativo de la red de dependencias de PyPI en dos snapshots: 2016 y 2025. Modela el ecosistema como grafos dirigidos para identificar el pivote del ecosistema hacia Data Science e IA.

**Stack:** Python, NetworkX, Louvain, Matplotlib, Gephi

---

### [Hands-on: Agente de RRHH con watsonx Orchestrate](Hands-on-UADE/)
Lab práctico para construir un agente conversacional de Recursos Humanos. El agente combina una base de conocimiento sobre beneficios de empleados con herramientas OpenAPI para leer y actualizar datos reales.

**Stack:** IBM watsonx Orchestrate, OpenAPI

---

### [Tech Summit — Labs de IA Agéntica y Streaming](Labs-tech-summit-main/)
Workshop de dos laboratorios: pipeline de inventario en tiempo real con Confluent Kafka y sistema multi-agente con watsonx Orchestrate para un caso de uso de retail.

**Stack:** Confluent Cloud (Kafka + ksqlDB), IBM watsonx Orchestrate, Python

---

### [OLGA — Compartí tu Momento](OLGA/)
Plataforma fullstack para que fans de OLGA suban videos o links de sus momentos favoritos. El backend descarga el contenido, lo procesa y lo sube automáticamente a las carpetas de Google Drive del canal.

**Stack:** Node.js, Express, Python, yt-dlp, Google Drive API, HTML, CSS, JavaScript, Bootstrap 5

---

### [Dashboard de Gastos Personales](Dashboards-gastos/)
Reporte interactivo de seguimiento mensual de gastos personales con modelo estrella, medidas DAX y limpieza en Power Query.

**Stack:** Power BI, DAX, Power Query
